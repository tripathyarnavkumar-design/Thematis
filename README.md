# Thematis

Thematis is a browser tool for thematic analysis of qualitative data. Upload or paste interview transcripts, open-ended survey responses or field notes, code passages with defined inclusion and exclusion criteria, group codes into themes, and export the codebook, theme book and a full analysis report.

Everything runs in the browser. Nothing you add is uploaded or stored; export a project file to keep your work.

The whole tool is one self-contained file, `index.html`. `og.jpg` is the image shown when the link is shared.
